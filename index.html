特殊交易日

当天全天关闭、全天开放，或恢复默认日历。操作会即时影响 `sessionAt` 与自主费率。

提前收盘

建议测试顺序：设置当天提前收盘并刷新核验；清除提前收盘；设为全天关闭；改为全天开放；最后恢复默认日历。提前收盘需在所设收盘时刻前提交才可验证当天的实时切换。

费率测试

双向费率测试

对应文档 2.3、4.2「覆盖、续期与清除」。填写两个交易方向的临时费率和持续时间，通过已连接钱包提交。

填 0 表示该方向沿用基础费率。两边都要恢复时，点击“恢复当前基础费率”。临时费率到期会自动失效，最多持续 72 小时。

写入 / 续期：调用 pokeFee(poolId, fee0For1, fee1For0, ttl)，双向值一起保存，到期时间从本次链上执行时刻重新计算。单边 0 沿用该方向自主费率；双边 0 拒绝。

清除覆盖：调用 clearPoke(poolId)。链上成功后，pokeOf 双向值与 expiry 都归零；tBTC 恢复 flat 费率，tQQQ / tCRCL 恢复当前日历时段自主费率。此操作不会修改基础配置。

自然到期：覆盖失效后恢复自主费率，但 pokeOf 中旧的双向值和 expiry 可能仍保留。不要把“到期失效”和“主动清除”当成同一状态。

对应文档 4.3：有效且非零的覆盖实际收费至少为当前自主费率的一半（按 pips 向下取整），并受请求下限与上限限制。普通周一至周四收盘后进入隔夜，周五收盘后进入休市；日历切换不改变存储的覆盖与 expiry。接口读值仅作参考，最终验收以 Swap 事件的 fee 为准。本轮不启用自动调费策略。
